Have a Google Photos link?

A web page is not allowed to read another website's page for you - the browser blocks it (a rule called CORS) and the file sits behind your Google session. So a link cannot be fetched inside this page, by this page or any other. Two ways round it:

  1. Press Open the link above (it opens in a new tab).
  2. In Google Photos, open the item and choose Download - pick Original quality if asked.
  3. Come back here and drop the downloaded file on the box above.

On a computer, the script does all three steps for you:
python3 pngwrap_unwrap.py --url "<link>"
It fetches the page itself (a script is not bound by the browser rule), downloads the items and restores whatever carries PngWrap data. Best effort, and it needs internet.

If a file says "re-encoded or transcoded"

Google Photos changed the image when it backed it up - that is what Storage saver does - so the original bytes are no longer inside. The wrapper holds fewer bytes than the original had, which is how it is detected. Nothing wrong is written out.

Very large files (several GB)

A browser has to hold the result in memory, and the page warns you above 2 GB. For a very large video use pngwrap_unwrap.py from the same release: it streams in 1 MB steps and never loads the whole file (measured: a 1.2 GB wrapper restored with 17.7 MB of memory).

How do I know the file that came out is really my original?

Every wrapper stores the original's name, exact size and SHA-256. This page recalculates that checksum while reading and refuses to save anything that does not match, so you never get a silently damaged file. The script prints the same checksum.
